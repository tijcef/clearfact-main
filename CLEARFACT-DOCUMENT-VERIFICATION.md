# ClearFact Document Verification

1. Install and activate `wordpress-plugin/clearfact-document-verification` on `cms.clearfact.ng`.
2. In WordPress, open **Document Verification → Register Official Document**.
3. Use IDs such as `CF/OL/2026/001`, `CF/SID/2026/001`, `CF/AP/2026/001`, `CF/MID/2026/001`, `CF/IC/2026/001`, `CF/AL/2026/001`, `CF/PL/2026/001`, or `CF/AC/2026/001`.
4. Publish the record. A secure token, verification URL, QR preview, download button and printable verification label will appear.
5. Deploy the updated ClearFact frontend. Public verification is at `https://clearfact.ng/verify`.
6. Before issuing any document, scan its QR and confirm that the displayed record matches the document.
